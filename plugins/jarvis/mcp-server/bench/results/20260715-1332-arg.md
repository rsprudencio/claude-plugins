# Jarvis retrieval benchmark

**Run:** 2026-07-15 13:32 UTC · **preset:** `arg` · **device:** `mps`

> Quality metrics (nDCG, STS, theta*) are hardware-independent. **Latency is not** - this ran on `mps`; production is CPU-only in Docker.

`nDCG@10` is the headline: Jarvis has a finite injection budget, so a memory ranked 9th is invisible even though it was found. **STS does not select models** — it disagrees with retrieval (bge-small: +0.08 STS, −0.04 nDCG). It only calibrates the threshold.
